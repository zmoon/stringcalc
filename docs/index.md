- {doc}`Web app & widgets <app>`

## Installation

stringcalc is available [on PyPI](https://pypi.org/project/stringcalc/):

```
pip install stringcalc
```

For the CLI, include the `cli` extra:

```
pip install stringcalc[cli]
```
